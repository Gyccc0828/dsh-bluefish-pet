# 蓝色大肥鱼桌宠 0.3.7-bluefish.20261025.1

基于 dsh-pet 0.3.7 的当前定制版本，现提供可复制到其他 DSH 的标准 `.tgz`。安装名称为 **`dsh-pet`**，项目仓库为 `dsh-bluefish-pet`。

## 更新内容

- **移动**：保留漫步，恢复原版奔跑中的“前扑摔倒 → 起身”完整过程，新增镜像右转奔跑；左右朝向与真实位移同步，贴边自动回头。螃蟹走路、左右漫步入口移除。
- **Claude 工作动作**：加入羽毛笔写字、左右递文件，与工作状态联动；两项动作待机概率为 0，手动菜单保留。基础 Claude 卫衣变装继续可用。
- **铁盆**：大而深、扣在额前的铁盆从上方落下，左右晃动后稳住；旧敲盆回弹和钢管动作移除。
- **时节**：21 个时节动作仅在对应节日／节气前后各七天自动触发，包含当天与窗口两端；支持农历、节气、跨年与午夜切换，随包离线历表覆盖 2020—2100 年；手动点播全年保留。
- **分发**：保留代码、默认配置、透明视频、字体、图标和素材说明，补齐分发版本、源文件校验与安装文档。原有查看余额、桌宠缩放和退出操作保留。

## 下载与安装

下载本 Release 的 `dsh-pet-0.3.7-bluefish.20261025.1.tgz`，无需解压，在 DSH 插件管理页的本地包入口选择它并重启。命令行方式：

```powershell
dsh plugin --profile desktop add .\dsh-pet-0.3.7-bluefish.20261025.1.tgz
```

网页模式使用 `--profile web`。若旧安装名称是 `dsh-bluefish-pet`，先停用或移除旧包，再安装本版 `dsh-pet`。已有同名插件的个人设置保留；用户自定义的完整 `animations` 段会覆盖新默认动作。首次安装或桌面启动可能下载依赖和 Electron。包内默认自动碎碎念开启，可在设置中关闭。

SHA-256：`2a7be57d91242e1d699a8070520b64c48d1e1691b8e559ad25deefcfda52c52b`。附件同时提供 `SHA256SUMS.txt`。
